# Algoritmo de Dijkstra Web

Implementación web del algoritmo de Dijkstra para el cálculo de caminos mínimos en grafos.

## 🚀 Funcionalidad
Este proyecto utiliza JavaScript para calcular la ruta óptima entre nodos. Incluye una interfaz web para visualizar los resultados y la estructura del grafo.

- **Lógica en JS**: Implementación pura del algoritmo (`Dijkstra.js`).
- **Interfaz Web**: Visualización mediante HTML5 y CSS3.
