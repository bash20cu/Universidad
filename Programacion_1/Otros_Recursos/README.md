# Otros Recursos y Ejercicios

Esta carpeta contiene ejercicios de práctica, código en clase, librerías y material complementario del curso de Programación 1.

## Contenido

- **Ejercicios/**: Prácticas generales de Java.
- **Arboles (ArbolBinario, ArbolBusqueda, binaryTree)**: Implementaciones y ejemplos de estructuras de datos de árboles.
- **Python (pyt*)**: Ejemplos comparativos o scripts de utilidad en Python.
- **Recursos (jar-lib, diagramas)**: Librerías externas y diagramas UML de soporte.
