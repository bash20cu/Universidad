# Powershell Scripts y Herramientas

Colección de scripts de automatización y herramientas de sistema desarrolladas en PowerShell y .NET.

## Proyectos

### 🛠 Services Control
Aplicación gráfica (WPF) para la gestión y control de servicios de Windows. Permite iniciar, detener y reiniciar servicios de manera visual y rápida.

**Características:**
- Interfaz moderna en WPF.
- Filtrado y búsqueda de servicios.
- Control de estado (Start/Stop/Restart).
