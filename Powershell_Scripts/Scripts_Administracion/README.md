# Scripts de Administración de Sistema

Este directorio contiene una colección de scripts en PowerShell diseñados para tareas de administración de sistemas y telemetría.

## Contenido

### 🔍 windows_telemetry.ps1
Script para gestionar y deshabilitar servicios de telemetría de Windows para mejorar la privacidad y el rendimiento.

### 🐘 postgres_service.ps1 / mysql_service.ps1 / mssql_service.ps1
Scripts de utilidad para gestionar el ciclo de vida (iniciar, detener, reiniciar) de servicios de bases de datos locales.

### 🧪 test.ps1
Script de pruebas para verificar configuraciones de entorno.
