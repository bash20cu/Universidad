# 🛠 Services Control

Aplicación de escritorio desarrollada en WPF (.NET 6.0) para la gestión ágil de servicios de Windows.

## 📋 Descripción

Services Control proporciona una interfaz gráfica moderna y rápida para visualizar, filtrar y controlar el estado de los servicios del sistema operativo. Es una alternativa ligera y eficiente a la herramienta nativa `services.msc`.

## ✨ Características

- **Interfaz Moderna**: Diseño limpio basado en WPF.
- **Búsqueda en Tiempo Real**: Filtra servicios por nombre o descripción instantáneamente.
- **Control de Estado**: Iniciar, Detener y Reiniciar servicios con un solo clic.
- **Indicadores Visuales**: Colores intuitivos para estados (Ej: Verde para "Running", Rojo para "Stopped").

## 💻 Requisitos

- Sistema Operativo: Windows 10 / 11
- Runtime: [.NET 6.0 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/6.0)

## 🚀 Ejecución

Para ejecutar la aplicación desde el código fuente:

1. Abrir la solución `Services_Control.sln` en Visual Studio 2022 o superior.
2. Compilar y ejecutar el proyecto.

Para usar el binario precompilado, consulta la carpeta `publish` o el enlace de descarga principal.
