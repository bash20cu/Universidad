# Laboratorio: Servicios WCF y Consola

Implementación de servicios web SOAP con WCF y consumo desde una aplicación de consola en .NET.

## 🛠 Tecnologías
![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white)
![.NET](https://img.shields.io/badge/.NET-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)

## 📖 Detalles
Este proyecto demuestra la arquitectura orientada a servicios (SOA) básico:
- **Laboratorio.SI.WCF**: Servicio WCF que expone operaciones de vehículos.
- **Laboratorio.SI.WebService**: Servicio ASMX heredado.
- **Laboratorio.UIConsole**: Cliente de consola que consume los servicios para interactuar con la lógica de negocio.
