# Base de Datos

Colección de laboratorios y proyectos enfocados en el diseño, implementación y administración de bases de datos.

## Contenido

Este curso abarca dos grandes áreas:

### Base de Datos 1
Introducción a los fundamentos de las bases de datos relacionales.
- **Normalización**: Procesos para organizar datos y reducir la redundancia.
- **Diagramas ER**: Modelado visual de entidades y relaciones.
- **SQL Básico**: Consultas de selección, inserción, actualización y eliminación.

### Base de Datos 2
Conceptos avanzados y administración.
- **T-SQL**: Procedimientos almacenados, triggers y funciones en Microsoft SQL Server.
- **Business Intelligence**: Introducción a SSIS, SSAS y cubos OLAP.
- **Análisis de Datos**: Uso de R y Python para análisis de sentimientos y minería de datos.
