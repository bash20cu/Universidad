# Laboratorio 2: Patrones de Impresión

Programa de consola que imprime patrones geométricos (cuadrados) utilizando asteriscos, permitiendo al usuario definir la longitud.

## 🛠 Tecnologías
![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)

## 📖 Detalles
Requerimientos:
1. Programa tipo consola.
2. Realizar la corrección en el código fuente para que la rutina imprima un cuadrado de `*` según la longitud solicitada.
3. Código documentado explicando la lógica de los ciclos.
