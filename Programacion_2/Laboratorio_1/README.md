# Laboratorio 1: Números Pares

Script en Python que verifica si un número es par o impar hasta un límite definido por el usuario.

## 🛠 Tecnologías
![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)

## 📖 Detalles
Se solicita desarrollar un programa que:
- Solicite un límite numérico al usuario.
- Analice los números desde el 2 hasta ese límite.
- Imprima en pantalla únicamente los números pares.
