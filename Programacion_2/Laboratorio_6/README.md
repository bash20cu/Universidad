# Laboratorio 6: Control de Aviones (Consola)

Sistema de consola para simular el control de tráfico aéreo utilizando listas.

## 🛠 Tecnologías
![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)

## 📖 Detalles
Funcionalidades:
- **Agregar Avión**: Registro en lista de espera.
- **Mostrar Lista**: Visualización FIFO (First In, First Out).
- **Despegue**: Eliminar avión de la lista.
- **Búsqueda**: Encontrar posición por número de vuelo.
- **Estadísticas**: Conteo total de aviones en espera.
