# Laboratorio 4: Manipulación de Cadenas

Herramienta de consola para realizar diversas operaciones de análisis y transformación sobre texto.

## 🛠 Tecnologías
![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)

## 📖 Detalles
El programa ofrece un menú con las siguientes opciones:
1. **Contar letras**: Determinar cuántas letras 'a' existen en una lista de provincias predefinida.
2. **Reemplazo**: Buscar la subcadena "es" en un texto y reemplazarla por "ES".
3. **Mayúsculas**: Convertir un texto ingresado por el usuario a mayúsculas.
