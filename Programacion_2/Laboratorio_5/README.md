# Laboratorio 5: Sistema de Inventario

Aplicación de consola para la gestión de un inventario de una verdulería utilizando listas y funciones.

## 🛠 Tecnologías
![Python](https://img.shields.io/badge/python-3670A0?style=for-the-badge&logo=python&logoColor=ffdd54)

## 📖 Detalles
Funcionalidades principales:
- **Agregar Fruta**: Inserta nuevas frutas al inventario.
- **Mostrar Inventario**: Lista todos los ítems disponibles.
- **Buscar**: Verifica la existencia de una fruta por nombre.
- **Total**: Calcula la cantidad de ítems.
- **Eliminar**: Permite sacar frutas del inventario validando cantidades.
